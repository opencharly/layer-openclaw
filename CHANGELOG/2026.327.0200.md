# 2026.327.0200 — fix(pins): advance the cachyos import to v2026.327.0134

## Summary

Advance the `cachyos` import from `distro-cachyos:v2026.325.1412` to **`v2026.327.0134`** in `charly.yml`, and update the pin's rationale comment to record the constraint that now holds it.

**Why.** The old pin's `box/charly-selftest` predates the build-vocabulary cutover (opencharly/spec#420): it still carries `build: [pac, aur]`, and `aur` is a BUILDER, never a build format. That is the repo-wide validate red the umbrella's pin wave hits (opencharly/layer-openclaw#14, opencharly/distro-cachyos#229).

**The three constraints the pin comment records were re-checked on the new tag**, not assumed:

1. **FLOOR** — `v2026.327.0134`'s `charly.yml` declares no retired openclaw pins (`gh api … distro-cachyos/contents/charly.yml?ref=v2026.327.0134` → no `openclaw` hit).
